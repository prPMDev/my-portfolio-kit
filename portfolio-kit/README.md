# Portfolio Kit

**Build a portfolio that stays alive.**

Building a portfolio got cheap. Keeping it current didn't. You ship something, switch jobs, and three months later your site is stale — off-voice, or quietly leaking a client's name. This kit is built for the part nobody else handles: keeping it true over time, in *your* voice, without leaking what you can't share.

No coding required. You talk; the skills do the work.

**Quick start:** once installed, just say *"help me build my portfolio."*

## What's inside (lean starter)

| Skill | What it does |
|-------|--------------|
| **setup** | Grabs the basics and sets up your profile. Start here. |
| **find-my-voice** | Extracts your real writing voice from things you've already written — not a dropdown of five archetypes. Everything else is written to match it. |
| **story-adapter** | Turns raw work into anonymized, on-voice case studies. Confidentiality and PII protection are built in. |
| **assemble** | Builds your approved content into a clean `index.html` you can open and publish — free, no terminal. |
| **refresh** | Keeps it all current as you ship, switch roles, or something becomes public. The reason this kit exists. |

## How to use it

1. Run **setup** — name, contact, anything you've written.
2. Run **find-my-voice** — so the writing sounds like you.
3. Run **story-adapter** — turn your wins into safe, sharp case studies.
4. Run **assemble** — build the page and put it online (free, no terminal).
5. Run **refresh** — anytime something changes. Make it a habit.

## The idea

- **Differentiation lives in your content and voice, not the template.** Same layout, your work and voice — that's still distinctly you.
- **Impact without identification.** Show what you achieved without naming what you can't.
- **Maintained beats stale.** A portfolio you keep current compounds; a copied template rots.

This is the lean starter. A fuller kit (hero/about copywriting, site building, SEO, a final quality gate) builds on top of these four.
